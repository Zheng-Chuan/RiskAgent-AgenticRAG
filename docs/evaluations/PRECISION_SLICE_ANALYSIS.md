# ragas precision slice 分析: v10e 0.675 -> v10f 0.511 的定量归因

日期: 2026-08-25
数据: [v10e](../../.artifacts/reports/rag_eval_prod_pipeline_v10e_crag_off_ab_20260824_104435.json) / [v10f](../../.artifacts/reports/rag_eval_prod_pipeline_v10f_crag_hybrid_20260825_031459.json) (同索引 manifest v4, 50 题, per-sample 对齐验证通过)
分析脚本: [p1_precision_slice.py](../../scripts/analysis/p1_precision_slice.py) / [p1_verify_hypothesis.py](../../scripts/analysis/p1_verify_hypothesis.py)
回答问题: precision 唯一退步项是口径假象还是真实退化, 是否需要处理.

## 结论先行

**口径假象为主 (约 0.08), 补位片段质量损耗为辅 (约 0.09), 混合策略本身影响在噪声内 (-0.05). 不构成回滚理由, 无需处理检索链路; 需要处理的是评测口径 (见建议).**

| 归因项 | 幅度 | 性质 |
|---|---|---|
| 重复片段计分灌水 (口径假象) | 0.675 -> 0.599 | v10e 的 0.675 是虚高, 分母含重复片段 |
| dedup 补位片段质量 | 0.599 -> 0.511 | 真实但已换来 recall +0.06 / faithfulness +0.093 |
| CRAG 混合策略 (sufficient 0.7) | -0.05 (无重复题组) | LLM judge 噪声量级, 可忽略 |

## 指标口径 (为什么会被重复片段灌水)

`ragas_context_precision_no_ref` 是自研指标, 不是 ragas 标准排名口径: 对每个 context 片段独立调用 LLM 判定 is_relevant + confidence, 片段分 = confidence (相关) / 0 (不相关), 题目分 = 片段简单平均, 汇总分 = 题目平均. 两个关键性质:

1. 与排序无关 (ranking 无关), 只看每个片段的相关性
2. 分母是片段数 — 重复出现的高分片段会被重复计入分子, 直接抬高平均分

而 SEAL dedup 修复前 (v10e), 正是 "高分 gold 片段跨轮重复占位" 的状态, 与该口径形成系统性正向偏置.

## 证据链

### 1. per-sample diff 总览

- 27 题下降 (>0.05), 3 题上升, 20 题持平; 平均 0.675 -> 0.511
- 下降题中 23/27 (85%) 在 v10e 存在重复片段

### 2. 有重复题 vs 无重复题的分解

| 组 | n | 平均 diff (v10f - v10e) | 说明 |
|---|---|---|---|
| v10e 有重复片段 | 34 | -0.218 | dedup + 补位双重影响 |
| v10e 无重复片段 | 16 | -0.052 | 纯混合策略影响 |
| 加权合成 | 50 | 34/50 x (-0.218) + 16/50 x (-0.052) = -0.165 | 与实测 -0.164 吻合, 分解自洽 |

### 3. 有效片段率 (灌水的直接证据)

- v10e: 表面 4.00 片段/题, 去重后平均 **3.28** 个不同片段
- v10f: 4.00 个不同片段 (50 题 0 重复, dedup 生效)
- v10e 的 precision 分子被重复片段重复计分, 等效于用 3.28 个片段的分数冒充 4.00 个

### 4. v10e 内部对照 (排除 "重复=高分所以全量灌水" 的简单解释)

v10e 有重复题 precision = 0.674, 无重复题 = 0.678, 基线相同. 说明重复集中在 "检索池浅" 的题 (gold 片段少, 两轮检索捞回同一批), 这些题天然低分, 重复片段的高分恰好把它们拉回平均 — 是选择偏差下的灌水, 而非无条件加分. 这也解释了为什么灌水幅度是 0.08 而不是更大.

### 5. 敏感性分析 (口径假象上界)

假设重复片段全部拿满分 confidence (s_dup=1.0, 最保守), v10e 去重不补位的口径 precision = (4 x prec - k x s_dup) / (4 - k) 逐题重算:

| s_dup 假设 | v10e 去重口径 | 判读 |
|---|---|---|
| 0.7 | 0.675 | 无变化 (巧合, 重复片段分数等于该题均分) |
| 0.9 | 0.624 | 典型高相关 gold 片段区间 |
| 1.0 (上界) | **0.599** | 口径假象最大解释力 0.076 |

即使最保守假设, 纯去重也只能降到 0.599, 与 v10f 实测 0.511 之间仍有 0.088 缺口 — 这部分是补位片段的真实质量损耗.

### 6. 补位片段构成 (损耗来源)

- 被挤掉的重复片段来源: Background.md (26) / wikipedia_xva (14) — 定义类 gold 高分片段
- 换入的新片段来源: bis_bcbs_d457.pdf (25) / bis_bcbs_d488.pdf (16) — 监管 PDF 其他章节, 与题面相关性弱于 gold 定义片段
- 案例实证:
  - q31 (What is Theta): 换入 wikipedia_xva 的 "OTC pricing 历史" 片段, 与 Theta 无关, 该题 0.850 -> 0.450
  - q41 (What is a risk factor): 四个片段全部被判不相关 (FRTB overview / LCR NSFR 等), 0.600 -> 0.000
- 但这些弱相关片段没有引入幻觉: v10f faithfulness 0.982 历史新高, contradiction 0.000, recall 0.800 — 补位片段是 "无害的冗余", 不是 "有害的噪声"

### 7. 分题型 slice

| tag | n | v10e | v10f | diff |
|---|---|---|---|---|
| definition | 46 | 0.671 | 0.508 | -0.164 |
| greek | 10 | 0.630 | 0.453 | -0.177 |

| procedure | 3 | 0.650 | 0.508 | -0.142 |

definition/greek 类下降最大 — 这些题的 gold 是定义片段, 最容易被两轮检索重复捞回 (v10e 受灌水最多); numeric 类反而上升, 多轮检索对数值题有真实增益. 符合 "假象集中在重复高发题型" 的预测.

## 判定与处置

**判定: 不构成回滚理由.** v10e 的 0.675 建立在 3.28/4.00 的有效片段率上, 是口径虚高; v10f 用 precision -0.164 (其中真实损耗约 0.09) 换来 recall +0.06 / faithfulness +0.093 / contradiction 清零, gate 阈值与基线全过.

**处置 (2026-08-25 项目收口)**: 曾提出的三个后续方向 — 评测口径对齐 (judge 前去重 contexts) / 新增 unique_context_ratio 观测指标 / ranking-aware precision 口径 — 经评审后全部决定不做, 理由: 口径对齐会改变历史基线可比性且不改变生产行为, 收益仅限评测报表整洁; 项目已收口, 不再投入.

**已知事实 (不再跟踪)**: q41 (risk factor) 在 v10f 检索到的 4 个片段全部弱相关, 属 v10f 整体 recall 0.80 下未命中 gold 的题目之一.
